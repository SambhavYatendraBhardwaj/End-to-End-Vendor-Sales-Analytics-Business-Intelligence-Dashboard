# 🛒 End-to-End Vendor Sales Analytics & Business Intelligence Dashboard

An end-to-end data analytics project performing Exploratory Data Analysis (EDA), SQL querying for business metrics, Python data wrangling, and an interactive Power BI dashboard to evaluate vendor profitability, shipping efficiency, and sales performance.

## 📌 Project Overview & Key Insights

This project analyzes vendor sales performance, purchase quantities, gross profit margins, and freight shipping costs to optimize procurement strategy and supply chain efficiency.

* **Total Sales Revenue:** **$333.01K** across all vendor transactions.
* **Total Purchase Volume:** **23K units** ordered.
* **Gross Profitability:** **$46.30K** overall net margins.
* **Total Freight Costs:** **$1.47K** spent on logistics.
* **Pareto Principle (80/20 Rule):** Identified top-performing brands and vendors driving majority of the revenue.

---

## 🛠️ Tech Stack & Workflow

* **Data Wrangling & Analysis:** Python (`Pandas`, `NumPy`)
* **Data Visualization (EDA):** `Matplotlib`, `Seaborn`
* **Querying & Aggregations:** SQL (MySQL/PostgreSQL)
* **Business Intelligence & Dashboard:** Microsoft Power BI Desktop
